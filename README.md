# 老七头倒计时

作者：**老七头** · GitHub 账号：[1q7713-maker](https://github.com/1q7713-maker)

## GitHub 绿勾是什么意思？

`Verify Windows preview` 是开发时的自动检查。绿勾表示配置的测试与编译通过，**不代表已经真机验收、公开发布或支持自动更新**。检查产物保存在私有源码库，不能作为给朋友的公开下载入口。

GitHub 显示的 `pushed by 1q7713-maker` 指提交代码的账号；软件和文档的作者署名是“老七头”。历史提交保留当时的记录。
