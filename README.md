# 老七头倒计时

作者署名：**将白** · 官方维护账号：[1q7713-maker](https://github.com/1q7713-maker)

桌面下班倒计时小工具：透明悬浮、置顶显示，可调整下班时间、大小和文字颜色，支持加班计时。
